## 仓库整理版与 API 102 迁移版

`0.4.1-alpha` 使用 v0.4 的应用内逻辑，应用标识迁移至规则文件，增加可重复构建、规则备份和恢复工具。它不包含 v0.3 的系统进程全宽首页钩子，也不包含未启用验证的 v0.5 状态栏偏移代码。

`0.6.0-alpha` 将模块迁移到官方 `io.github.libxposed:api:102.0.0`，移除旧 API 82。它需要支持 API 102 的框架；上表中的 Vector 2.2 支持这个接口，但迁移版本尚未在该平板上安装验证。双栏规则不随本次接口迁移改变。B 站全屏缩放过渡、酷安首页标签边缘截断仍是待处理反馈，不包含在本次迁移中。

`0.7.0-alpha` 增加旅法师营地（`com.gonlan.iplaymtg`）的广告拦截，基于对该应用 9.2.7 的反编译分析：拦截聚合广告管理器 `g.i.a.u.q2.b` 的 8 个入口（开屏、插屏、激励视频、信息流）、自建开屏缓存 `g.i.a.l.b.d` 与"我的"页横幅数据 `MineADBean` 的文本字段。广告回调按 `failed()` 通知，应用自身的无广告路径（开屏失败进主页、信息流空数据跳过）已逐一核对。该功能尚未在平板上验证。

本地测试检查规则变换、CLI 转义、备份保护、写入后失败的回滚、外部变更保护。构建另运行 9 项基于真实 API 102 接口和生产 HookFlow 的调用链检查，以及 APK 元数据 / DEX 依赖检查。它们不能替代平板上的真实界面与稳定性验证。当前没有连接平板，不自动安装迁移版。

## 已知问题

- 多次 APK 更新等待期间出现 ADB 长时间无响应，最近一次伴随设备完全卡死。原因未确定，不能认定为某个应用钩子导致，也不能认定已经修复。
- 当时状态栏偏移代码尚未加入 SystemUI 作用域，未验证生效；本仓库不包含它。
- 酷安启动补充逻辑可能与系统附属页启动存在重复触发边界，仍需更多返回栈和恢复场景验证。
- 系统更新、应用页面类名变化或规则刷新可能使适配失效。
